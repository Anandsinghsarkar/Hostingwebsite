🚀 Getting Started

  1. Login with Google
  2. Click Create Bot from the sidebar
  3. Upload your .py / .js / .zip file
  4. Go to My Bots and click ▶ Start
  5. View real-time logs with the 📜 Logs button

📦 Dependencies

Include requirements.txt (Python) or package.json (Node.js) in your zip. They will be auto-installed.
